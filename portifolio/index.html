// À propos

Du design à la base de données

Je suis Mahouna, développeur full-stack : je conçois des applications web complètes, de l'interface à la base de données.

Je travaille aussi bien sur l'interface (React, HTML, CSS) que sur le serveur (Node.js, FastAPI), les API REST, l'authentification et les bases de données. J'ai une affinité particulière pour le backend : API, bases de données et logique serveur. Un seul interlocuteur pour tout le projet, c'est moins d'allers-retours et un résultat cohérent.

Ma façon de travailler : des points d'avancement clairs, des estimations honnêtes et du code lisible, centré sur ce dont votre projet a vraiment besoin.
